## 2. 数据结构

```ts
interface Category {
  id: 'deduction' | 'fine' | 'abbr' | 'speed';
  name: string;       // 完整名称，如「交规扣分」
  shortName: string;  // 2-4 字简称
  en: string;         // 大写英文眉题，如「PENALTY POINTS」
  tagline: string;    // 4-24 字，一句海报语
  intro: string;      // 12-90 字，方向介绍
  groups: string[];   // 3-6 个，顺序即筛选顺序
  cards: LearningCard[];
  questions: ChallengeQuestion[];
  achievements: Achievement[];
}

interface LearningCard {
  id: string;        // dd-01 / fn-01 / ab-01 / sp-01，按数组顺序连续编号
  group: string;     // 必须是 groups 中的一项
  title: string;     // 2-20 字，卡片标题
  original: string;  // 原文：法规原文（交规扣分为逐字原文；其他分类为精炼版），20-220 字
  source?: string;   // 法规出处，如《道路交通安全违法行为记分管理办法》第八条第（一）项
  memory: string;    // 辅助记忆：口诀/对比/场景联想，8-100 字
}

interface ChallengeQuestion {
  id: string;        // qdd-01 / qfn-01 / qab-01 / qsp-01，连续编号
  cardId: string;    // 关联学习卡片 id；答后翻面展示这张原卡，必须是本方向 cards 中的 id
  group: string;     // 必须是 groups 中的一项
  stem: string;      // 8-100 字，题干
  options: [string, string, string, string]; // 恰好 4 项，互不重复，每项 ≤ 50 字
  answer: 0 | 1 | 2 | 3;                     // 正确项下标
  explanation: string;                       // 12-160 字，讲清正确规则 + 易错点
}

interface Achievement {
  id: string;        // dd-a1 … dd-a6（fn-/ab-/sp- 同理）
  title: string;     // 2-10 字
  desc: string;      // 4-26 字，必须直白写清解锁条件
  icon: 'route' | 'book' | 'bolt' | 'target' | 'crown' | 'flag' | 'shield' | 'spark' | 'gauge' | 'stamp';
  metric: 'mastered' | 'challenge' | 'perfect' | 'correct';
  target: number;
}
```

## 3. 内容要求（重要）

**语气**：学习笔记，不是教材搬运。原文准确、干净；辅助记忆要真的能帮人记住，禁止复述原文。

- 所有字段使用中文全角标点；**不要** Markdown、HTML、emoji、换行符、首尾空格。
- 原文可以精炼长句，但**分值、金额、速度、距离、百分比、条件**必须准确；不要写「一般」「大概」。
- 卡片标题要具体：写「高速倒车、逆行」而不是「高速公路的违法行为」。
- 辅助记忆要提供真正的记忆抓手：数字口诀、场景联想、对比辨析、谐音/顺口溜皆可，一句话讲清，避免"要记牢""很重要"这类空话。
- 同一分类内卡片不得重复或同义反复；每张卡只承载一个可考的知识点。
- 题目难度接近真实科目一：场景题、数字题、辨析题混合；**答案必须能从本分类卡片中找到依据**。
- 题干不得依赖图片、「看图」「上题」等上下文；选项之间不得有包含关系；避免「以上都对/都不对」。
- 选项只放答案本身的关键差异，不要复述题干主语：分数题只写分值，罚款题只写金额 / 吊销 / 拘留，缩写题只写缩写，车速车距只写数字。比较题用「x / y」并保持题干出现顺序，例如「货车与中型以上载客汽车分别记多少分？」的选项写「3分 / 9分」。
- 英文缩写题固定为「题干描述功能 / 场景，选项是 4 个缩写」，不要出「关于 X 与 Y 的分工，下列说法正确的是」这类判断题。
- 准驾车型题优先考「代号 ↔ 准驾车辆」「申请年龄」「初次申领 / 增驾条件」；不要用总质量 4500kg、发动机排量等超细参数作为题干或选项。
- 不要把题干写成「关于……下列说法正确」后让选项承载整句判断，选项应是分值、金额、缩写、代号、年龄等可以直接判断的答案。
- 正确选项位置要打散：A/B/C/D 各至少 4 题，单一位置不超过总题数 50%。
- 解析 = 正确答案依据 + 易错点，不要只写「选 B」。
- 每道题的 4 个选项要通过 `readonly` 元组字面量写（`options: ['…', '…', '…', '…']`）。

### 成就（6 个，模板固定）

每个分类恰好 6 个成就，**必须**按下面的 metric/target 组合（顺序可自定，id 按顺序 a1…a6），标题/描述/图标可自由设计但须贴合该方向：

| # | metric | target | 含义 |
|---|---|---|---|
| 1 | `mastered` | `1` | 掌握第 1 张卡片 |
| 2 | `mastered` | `Math.ceil(cards.length / 2)` | 掌握一半卡片（20 张 → 10；18 张 → 9） |
| 3 | `mastered` | `cards.length` | 掌握全部卡片（20 或 18） |
| 4 | `challenge` | `1` | 完成第 1 次 10 题挑战 |
| 5 | `perfect` | `1` | 挑战拿到 10/10 |
| 6 | `correct` | `30` | 累计答对 30 题 |

- `desc` 直白写条件，例如「掌握全部 20 张卡片」「累计答对 30 道题」；可带一点方向气质，但不要含糊。
- 6 个成就使用 6 个**不同**的 icon；图标语义见下：
  `route` 路线节点 / `book` 书与卡片 / `bolt` 连击与能量 / `target` 精准命中 / `crown` 冠军 / `flag` 里程碑 /
  `shield` 安全守护 / `spark` 新星亮起 / `gauge` 仪表与控速 / `stamp` 官方印章。
- 标题示例（可参考，欢迎更好）：扣分「初次上路 / 半本驾照 / 零扣分司机 / 首战开张 / 满分车手」；罚款「第一张罚单 / 半程护钱包 / 钱包守门员」；缩写「字母新手 / 半程解码 / 缩写翻译官」；车速「起步看表 / 半程控速 / 人肉限速牌」。

## 4. 已核实的参考资料

### 4.1 交规扣分（2022-04-01 起，公安部令第 163 号《道路交通安全违法行为记分管理办法》）

官方全文：<https://www.gov.cn/gongbao/content/2022/content_5679697.htm>

**12 分（7 项）**
1. 饮酒后驾驶机动车。
2. 造成致人轻伤以上或者死亡的交通事故后逃逸，尚不构成犯罪。
3. 使用伪造、变造的机动车号牌、行驶证、驾驶证、校车标牌，或者使用其他机动车号牌、行驶证。
4. 驾驶校车、公路客运汽车、旅游客运汽车载人超过核定人数 20% 以上；驾驶其他载客汽车载人超过核定人数 100% 以上。
5. 驾驶校车、中型以上载客载货汽车、危险物品运输车辆在高速公路、城市快速路上超速 20% 以上；驾驶其他机动车在高速公路、城市快速路上超速 50% 以上。
6. 在高速公路、城市快速路上倒车、逆行、穿越中央分隔带掉头。
7. 代替实际驾驶人接受处罚和记分牟取经济利益（买分卖分）。

**9 分（7 项）**
1. 驾驶 7 座以上载客汽车载人超过核定人数 50% 以上未达 100%。
2. 驾驶校车、中型以上载客载货汽车、危险物品运输车辆在高速公路、城市快速路以外的道路超速 50% 以上。
3. 在高速公路或城市快速路上违法停车。
4. 驾驶未悬挂号牌或故意遮挡、污损号牌的机动车上道路行驶。
5. 驾驶与准驾车型不符的机动车。
6. 未取得校车驾驶资格驾驶校车。
7. 连续驾驶中型以上载客汽车、危险物品运输车辆超过 4 小时未停车休息，或停车休息时间少于 20 分钟。

**6 分（11 项）**
1. 载客超员：校车/公路客运/旅游客运超员未达 20%；7 座以上载客汽车超员 20% 以上未达 50%；其他载客汽车超员 50% 以上未达 100%。
2. 校车/中型以上载客载货/危险品运输车在高速、快速路超速未达 20%，或在其他道路超速 20% 以上未达 50%。
3. 上述车辆以外的机动车在高速、快速路超速 20% 以上未达 50%，或在其他道路超速 50% 以上。
4. 驾驶载货汽车载物超过最大允许总质量 50% 以上。
5. 载运爆炸物品、易燃易爆化学品、剧毒、放射性等危险物品，未按指定时间、路线、速度行驶，或未悬挂警示标志并采取安全措施。
6. 运载超限不可解体物品，未按指定时间、路线、速度行驶，或未悬挂警示标志。
7. 运输危险化学品未经批准进入限行区域。
8. 不按交通信号灯指示通行（闯红灯）。
9. 驾驶证被暂扣或扣留期间驾驶机动车。
10. 造成致人轻微伤或财产损失的交通事故后逃逸，尚不构成犯罪。
11. 在高速公路或城市快速路上违法占用应急车道行驶。

**3 分（15 项）**
1. 其他载客汽车（校车/营运/7 座以上以外）超员 20% 以上未达 50%。
2. 其他机动车在高速、快速路以外道路超速 20% 以上未达 50%。
3. 在高速、快速路不按规定车道行驶。
4. 不按规定超车、让行，或在高速、快速路以外道路逆行。
5. 前方排队/缓行时借道超车、占用对面车道、穿插等候车辆。
6. 拨打、接听手持电话等妨碍安全驾驶。
7. 行经人行横道不按规定减速、停车、避让行人。
8. 不按规定避让校车。
9. 载货汽车载物超过最大允许总质量 30% 以上未达 50%，或违反规定载客。
10. 不按规定安装机动车号牌。
11. 车辆故障/事故停车后，不按规定使用灯光或设置警告标志。
12. 驾驶未按规定定期检验的公路客运、旅游客运、危险物品运输车辆。
13. 驾驶校车前未检查车况，或驾驶存在安全隐患的校车。
14. 连续驾驶载货汽车超过 4 小时未停车休息，或休息少于 20 分钟。
15. 在高速公路上行驶低于规定最低时速。

**1 分（10 项）**
1. 校车/中型以上载客载货/危险品运输车在高速、快速路以外超速 10% 以上未达 20%。
2. 不按规定会车，或在高速、快速路以外不按规定倒车、掉头。
3. 不按规定使用灯光。
4. 违反禁令标志、禁止标线指示。
5. 载货长度、宽度、高度超过规定。
6. 载货汽车载物超过最大允许总质量未达 30%。
7. 驾驶未按规定定期检验的上述三类车辆以外的机动车。
8. 驾驶擅自改变已登记结构、构造或特征的载货汽车。
9. 驾驶人未按规定系安全带。
10. 驾驶摩托车不戴安全头盔。

**记分规则（可用于「记分规则」分组）**
- 记分周期 12 个月，满分 12 分，自初次领证之日起连续计算。
- 一个记分周期内累积记分满 12 分：扣留驾驶证，参加 7 天满分学习并考试；大中型客货车驾驶人参加 30 天。
- 一个记分周期内二次满 12 分或累积 24–35 分：学习考试合格后，加考道路驾驶技能。
- 累积未满 12 分且无未缴罚款：周期届满记分清零；有罚款逾期未缴的，记分转入下一周期。
- 学法减分：网上学习 3 日内累计满 30 分钟且考试合格一次减 1 分；现场学习满 1 小时且考试合格一次减 2 分；公益活动中满 1 小时一次减 1 分。一个记分周期累计最高减 6 分。

### 4.2 交规罚钱（《道路交通安全法》2021 修正 + 实施条例）

> 罚款幅度为国家规定区间，各地实施细则可能不同；卡片/题目只写国家区间。

- **20–200 元**：机动车驾驶人违反道路通行规定（第 90 条，警告或 20–200 元）；违反停放、临时停车规定且拒绝驶离妨碍通行（第 93 条，20–200 元，可拖移）。
- **200–2000 元**（第 99 条，8 种情形）：
  1. 无证驾驶（未取得、被吊销、被暂扣期间驾驶）；
  2. 将车交给无证/被吊销/被暂扣驾驶证的人驾驶；
  3. 造成交通事故后逃逸，尚不构成犯罪；
  4. 行驶超过规定时速 50%；
  5. 强迫驾驶人违规驾驶，造成交通事故尚不构成犯罪；
  6. 违反交通管制规定强行通行，不听劝阻；
  7. 故意损毁、移动、涂改交通设施，造成危害后果尚不构成犯罪；
  8. 非法拦截、扣留机动车，不听劝阻，造成严重堵塞或较大财产损失。
  - 第 2、4 项可并处吊销驾驶证；第 1、3、5–8 项可并处 15 日以下拘留。
- **2000–5000 元**：
  - 伪造、变造或使用伪造、变造的机动车登记证书/号牌/行驶证/驾驶证：收缴、扣留机动车、15 日以下拘留，并处 2000–5000 元（第 96 条）；
  - 使用其他车辆的登记证书/号牌/行驶证/检验合格标志/保险标志：收缴 + 2000–5000 元。
- **酒驾/醉驾（第 91 条）**：
  - 饮酒后驾驶：暂扣 6 个月驾驶证 + 1000–2000 元；
  - 因饮酒驾驶被处罚后再次饮酒驾驶：10 日以下拘留 + 1000–2000 元 + 吊销驾驶证；
  - 饮酒后驾驶营运机动车：15 日拘留 + 5000 元 + 吊销驾驶证 + 5 年内不得重新取得；
  - 醉酒驾驶：约束至酒醒 + 吊销驾驶证 + 依法追究刑事责任 + 5 年内不得重新取得；
  - 醉酒驾驶营运机动车：吊销 + 刑责 + 10 年内不得重新取得，重新取得后不得驾驶营运机动车；
  - 饮酒或醉酒驾驶发生重大交通事故构成犯罪：吊销 + 终生不得重新取得。
- **车辆与证件**：
  - 驾驶拼装车/已达报废标准车：收缴强制报废 + 200–2000 元 + 吊销驾驶证（第 100 条）；出售报废车：没收违法所得 + 销售金额等额罚款。
  - 未投保交强险：扣留车辆至投保后 + 应缴最低责任限额保费的 2 倍罚款（第 98 条）。
  - 非法安装警报器、标志灯具：强制拆除、收缴 + 200–2000 元（第 97 条）。
  - 重大事故构成犯罪：吊销驾驶证；造成交通事故后逃逸：吊销 + 终生禁驾（第 101 条）。
- **营运与超载（第 92 条）**：
  - 公路客运超员：200–500 元；超员 20% 以上或违规载货：500–2000 元；
  - 货运超载：200–500 元；超载 30% 以上或违规载客：500–2000 元；
  - 上述情形可扣留机动车至违法状态消除；运输单位经处罚不改的，对直接负责的主管人员处 2000–5000 元。

### 4.3 英文缩写（选择 20 个，来自下列已核对清单）

### 4.4 车速车距（《道路交通安全法实施条例》）

- **高速公路（第 78 条）**：最高 120 km/h，最低 60 km/h。小型载客汽车最高 120；其他机动车最高 100；摩托车最高 80。
  - 同方向 2 条车道：左侧最低 100，右侧最低 60。
  - 同方向 3 条以上车道：最左侧最低 110，中间最低 90，右侧最低 60。
  - 限速标志标明的车速与上述规定不一致时，按限速标志行驶。
- **没有限速标志的普通道路（第 45 条）**：没有道路中心线——城市道路 30 km/h、公路 40 km/h；同方向只有 1 条机动车道——城市道路 50 km/h、公路 70 km/h。
- **最高 30 km/h 的情形（第 46 条）**：进出非机动车道、通过铁路道口、急弯路、窄路、窄桥；掉头、转弯、下陡坡；遇雾/雨/雪/沙尘/冰雹能见度 50 米以内；在冰雪、泥泞道路行驶；牵引发生故障的机动车。（拖拉机、电瓶车、轮式专用机械车为 15 km/h）
- **高速跟车距离（第 80 条）**：车速超过 100 km/h 时，与同车道前车保持 100 米以上；车速低于 100 km/h 时，距离可适当缩短，但最小不得少于 50 米。
- **低能见度三档（第 81 条）**：
  - 能见度 < 200 米：开雾灯、近光灯、示廓灯、前后位灯；车速 ≤ 60 km/h；与前车保持 100 米以上；
  - 能见度 < 100 米：再加开危险报警闪光灯；车速 ≤ 40 km/h；与前车保持 50 米以上；
  - 能见度 < 50 米：开启上述全部灯光；车速 ≤ 20 km/h；从最近出口尽快驶离高速公路。
- **停车距离（第 63 条）**：交叉路口、铁路道口、急弯路、宽度不足 4 米的窄路、桥梁、陡坡、隧道以及距离上述地点 50 米以内不得停车；公交站、急救站、加油站、消防栓或消防队（站）门前以及距离上述地点 30 米以内不得停车。
- 夜间会车应在距相对方向来车 150 米以外改用近光灯（第 48 条第（五）项，适用于没有中心隔离设施或者没有中心线的道路）。
