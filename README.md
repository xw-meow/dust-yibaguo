# 一把过 · 科目一卡片训练场

> 把交规，开成肌肉记忆。

一个用「卡片学习 + 十题挑战 + 成就系统」组成的科目一备考应用。五个方向各自成站，先学后练，学习与挑战进度全部保存在本机浏览器。

手机优先，首页按 App 的方式组织：没有顶部导航，一屏内完成方向选择。

## 功能

### 五个训练方向

| 方向 | 内容 | 卡片 | 题目 | 成就 |
| --- | --- | ---: | ---: | ---: |
| 交规扣分 | 163 号令全部 50 条记分行为 + 5 条记分规则 | 55 | 55 | 6 |
| 交规罚钱 | 通行、停车、无证、逃逸、牌证、酒驾等罚款与拘留 | 18 | 22 | 6 |
| 英文缩写 | ABS、EBD、TCS、ESP、ACC、AEB 等车载系统 | 20 | 24 | 6 |
| 车速车距 | 高速 / 普通道路限速、能见度车速车距、停车距离 | 18 | 22 | 6 |
| 准驾车型 | 17 个准驾车型代号、年龄、增驾、实习期规则 | 28 | 28 | 6 |

合计 **139 张卡 / 151 题 / 30 枚成就**；五个方向各自独立计算进度与成就。

### 学习模式

- 一张一张的竖版卡片，左右滑动 / 方向键切换；卡面占满可用宽度，不再放两侧切换按钮。
- 支持预设分组筛选：例如扣分可按 12 / 9 / 6 / 3 / 1 分与记分规则筛选。
- 每张卡固定为 **标题 / 原文 / 法规出处 / 辅助记忆**；数字和缩写会被荧光笔标出。
- 卡片正文可上下滚动，但页面本身不滚动。
- 不再手动标记掌握：按挑战中的累计作答自动判定，卡面材质随「了解 / 熟悉 / 掌握」变化。

### 挑战模式

- 每轮随机抽 **10 题**，四选一；左右滑动或方向键切题。
- **选项只保留答案本身的关键差异**，不复述题干：分数题只给分值，罚款题只给金额 / 吊销 / 拘留，缩写题只给缩写，车速车距只给数字。
- 选中答案后 3D 翻面展示对应的原卡：答对为绿色卡背，答错为红色卡背，并用大号 ✓ / ✕ 取代数字水印。
- 答完后可以**点按卡片**在原卡与刚才的题目选项之间来回翻转；回看选项时，之前选中的项用红色（错）或绿色（对）粗边框高亮并标「你选的」，同时用绿色标出正确答案。
- 挑战过程不显示分数，支持键盘 `1–4` 作答、方向键切题。
- 「放弃本次」需要二次确认，放弃的轮次不写入记录。

### 成绩页

- 10 题全部答完后，先停在最后一题的卡背；**左滑或点「查看成绩」**进入成绩页。
- 成绩页是卡组最后一张卡：成绩页**右滑回看最后一题**，最后一题**左滑又回到成绩页**。
- 按得分率分为「满分车神 / 准车神 / 压线车手 / 回炉选手」四档，对应不同浅色主题、趣味文案与循环装饰动画。
- 展示得分、正确率和鼓励语；只有一个「再来一次」按钮。

### 掌握度

- 每张卡在挑战中累计作答满 **10 次**后，按累计正确率判定：
  - `≥60%`：了解
  - `≥80%`：熟悉
  - `100%`：掌握
- 不满 10 次为待判定；放弃的轮次和之前的手动掌握标记都不再计入。
- 「掌握」的卡片计入总进度与本方向的掌握类成就。

### 成就与进度

- 每个方向 6 枚成就，分类页「成就」页签可查看进度；首页右上角另有全站 30 枚成就页。
- 成就解锁提示为居中浮窗，一次只显示一条，5 秒后自动消失，且不拦截卡片滑动。
- 每张卡的作答次数 / 正确次数、掌握等级、最佳成绩、挑战次数与已解锁成就保存在 `localStorage`（`yibaguo.progress.v2`），刷新不丢；首页右上角的小图标可清空全部进度，点击后会弹出二次确认。

## 技术栈

- Vite 8 + React 19 + TypeScript
- [Motion](https://motion.dev/)（`motion/react`）：页签切换、卡片进场与拖拽切卡、挑战 3D 翻面、成就浮窗
- 纯 CSS 设计系统（自定义属性 + 响应式布局），无 UI 框架依赖
- Hash 路由：`#/` 首页、`#/achievements` 全站成就页、`#/c/<category>` 训练页

## 本地开发

```bash
npm install
npm run dev        # http://localhost:5173

npm run build      # 类型检查 + 生产构建，产物在 dist/
npm run preview    # 本地预览生产构建

npm run lint       # oxlint
npm run check      # tsc -b + 全量内容校验
```

内容校验命令：

```bash
npm run validate:data       # 五个方向的数量 / 字段 / 成就 / 答案分布
npm run validate:deduction  # 扣分 55 卡 / 55 题与 163 号令原文逐字一致
npm run validate:license    # 准驾车型 28 卡 / 28 题与 172 号令原文一致
```

## 设计说明

- **主色板**：`#2373F4` `#578EF5` `#65D0F4` `#F2F7A0`，按需派生浅色 tint、深色 ink 与语义色（正确 / 错误 / 强调）；正文、按钮与卡面文字均按 WCAG AA 对比度检查。
- **手机首页**：便当格布局，交规扣分占整行，其余四个方向两两成格；顶部的总进度是只读暗色仪表带，不做成可点击卡片；下方训练方向使用带实心箭头的彩色卡片，点击反馈明确。五个方向以 `12`、`¥`、`ABC`、`120`、`C1` 作为巨型水印题眼。右上角小图标用于清空进度，点击后弹出二次确认。
- **一屏布局**：首页与分类页锁定一屏高度，切换页签 / 筛选不产生整页滚动；只有卡片正文、筛选条和成就列表在各自区域内滚动。
- **卡牌视觉**：原文用宋体排印，数字与缩写用荧光笔标出；辅助记忆落在浅黄便签上；卡片下方叠卡暗示可滑动。
- **翻面与反馈**：挑战卡使用 3D 翻面；答对 / 答错切换绿色 / 红色卡背与 ✓ / ✕ 背景；回看选项时选中项和正确答案都有明确色块与标签，不靠想象。
- **动效克制**：进场、转场、答题、成就各自有一套动效；成绩页保留庆祝用的循环装饰（旋转虚线环、彩纸、漂浮色块、闪光），并尊重系统 `prefers-reduced-motion` 设置。
- **焦点与键盘**：移动端点击后不显示常驻蓝色焦点框，键盘 Tab 仍保留可见焦点；挑战支持 `1–4` 作答与方向键切题，卡片翻面也有可聚焦的「看选项 / 看原卡」按钮。
- **性能**：不使用吸顶模糊与 `backdrop-filter`；卡片切换 / 翻面只动 `transform`、`opacity`，并对拖拽与翻面层做 `will-change`，减少手机掉帧。

## 内容口径

- 记分规则按 **《道路交通安全违法行为记分管理办法》（公安部令第 163 号，2022-04-01 施行）** 整理；截至 2026-10-21 核对仍为现行有效版本。
- 每道挑战题通过 `cardId` 关联一张学习卡，答后翻面展示的「原卡」即对应卡片；`npm run validate:data` 会校验该关联是否存在。
- 交规扣分覆盖第八至十二条 **全部 50 条记分行为**，另附 5 条记分规则；50 条行为的卡片原文与法规逐字一致，机读基准见 `docs/sources/score-points-163.json`（官方来源：[公安部](https://app.mps.gov.cn/gdnps/zc/content.jsp?id=8282949)、[国务院公报](https://www.gov.cn/gongbao/content/2022/content_5679697.htm)）。
- 准驾车型按 **《机动车驾驶证申领和使用规定》（公安部令第 172 号，2025-01-01 施行）** 及附件 1 整理：17 个准驾车型代号、准驾车辆、可开车型，另附年龄、增驾、实习期、准驾不符 11 条规则；机读基准见 `docs/sources/license-classes-172.json`（官方来源：[国务院公报](https://www.gov.cn/gongbao/2025/issue_11866/202502/content_7004031.html)）。
- 罚款按《道路交通安全法》（2021 修正）及《道路交通安全法实施条例》整理，只写国家法定幅度，不写地方细化标准。
- 英文缩写取常见车载系统的规范全称与功能；车速车距按《道路交通安全法实施条例》第 45 / 46 / 48 / 63 / 78 / 80 / 81 条整理。
- 内容仅供备考练习，具体处罚以现行法规与当地执行标准为准。
